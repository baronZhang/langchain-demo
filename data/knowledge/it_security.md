# 星河科技 IT 与信息安全规范（虚构示例数据）

## 账号与密码

公司账号密码长度至少 12 位，必须包含大小写字母、数字和特殊字符，每 90 天强制更换一次。
禁止多人共用账号；离职当天由 IT 部门回收全部账号权限。

## 数据分级

公司数据分为公开、内部、机密、绝密四级。机密及以上数据禁止通过个人邮箱、网盘或即时通讯工具外发。
客户数据属于机密级，导出客户数据需要提交数据导出申请，并经数据安全委员会审批。

## AI 工具使用规范

允许使用公司采购并部署的大模型平台处理内部数据。
严禁将源代码、客户数据或机密文档粘贴到未经批准的公共 AI 工具中。
使用 AI 生成的代码必须经过同事 Code Review 后才能合并到主分支。
